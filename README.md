# devops-nodejs-k8s-cicd

DevOps project: Node.js app deployed on AWS EC2 with Minikube (Kubernetes), Docker, ECR, and GitHub Actions CI/CD.

**Student:** M Ali Zia (78443)

## Endpoints
- `/` — Main dashboard
- `/health` — Health check (JSON)
- `/api/info` — App info (JSON)

## Stack
- Node.js + Express
- Docker + Amazon ECR
- Kubernetes (Minikube on EC2 t2.micro)
- GitHub Actions CI/CD
- AWS Free Tier
